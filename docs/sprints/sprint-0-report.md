## מה נבנה
- **פלטפורמה: Firebase** (ADR 0008): Auth, Firestore (eur3), Storage, Functions (europe-west1), Pub/Sub, Cloud Run ל-worker, Hosting. החליף את Supabase לבקשת הבעלים.
- **Web:** התחברות, רשימת פרויקטים, העלאת סט, ושלד סביבת הבדיקה עם RTL ושפת הביטחון (●▲◆). 89 בדיקות.
- **API (NestJS ב-Functions):** אימות ID token, הרשאות לפי תפקיד, העלאה עם בדיקת magic bytes ו-dedupe לפי sha256, ותור ingest. 70 בדיקות.
- **Security Rules** ל-Firestore ול-Storage, עם חבילת בדיקות באמולטור שרצה ב-CI.
- **CI:** Node, Python, rules, gitleaks, Semgrep, osv-scanner, Docker ו-Trivy, ושער kbench. כל ה-actions נעוצים ל-SHA.
- **kbench:** כל מדדי תוכנית הבדיקות ושער רגרסיה. 45 בדיקות.
