## פתוח
- **DWG:** אין עדיין `dwg2dxf` ב-image. בינתיים קובץ DWG מקבל שגיאה מוקלדת.
- **אישור ב-Cloud Run:** יש לוודא שה-sandbox פועל ב-Cloud Run gen2 בפריסה הראשונה.
- **ביטחון ירוד בהתחלה:** הגיליונות הראשונים של ארגון חדש מקבלים ביטחון נמוך יותר (מילון גליפים "קר").
- **קבצים ענקיים:** חילוץ נתיבים איטי בקבצי A0 גדולים מאוד (מעל 1.5 מיליון נתיבים).
